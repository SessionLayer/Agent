{{- if not .Values.persistence.enabled }}

persistence is off, so the Agent's identity is an emptyDir and does not survive
a pod restart. The next start re-joins, the Control Plane refuses a node whose
identity is still active, and the pod exits 4 and stays down:

  identity refused by the Control Plane - not transient, do not auto-restart
  into a loop ... exit_code=4

Recovering means deleting the node in the Control Plane and issuing a fresh
join credential, by hand, per node. Set persistence.enabled=true for any
cluster where a node reboot, an image bump or a rollout can happen.
{{- end }}
